# Configurações
------

Em config.txt colocar:
<br> 
  ⋅⋅* entrada (valor da entrada)
  <2> 
  ⋅⋅* stop_win e stop_los;
  <br> 
  ⋅⋅* tipo de conta;
  <br> 
  ⋅⋅* martingale (S ou N)
  <br> 
  ⋅⋅* valorGale
  <br> 
  ⋅⋅* niveis (quantidade de MT)
  <br> 
  ⋅⋅* analisarTendencia (S ou N)
  <br> 
  ⋅⋅* noticias (S ou N)
<br> 
Instalar as dependencias necessarias:<br>
<p>pip install -r requirements.txt<p>
<br>
Para executar o robo: <br>
<p> python main.py </p>
